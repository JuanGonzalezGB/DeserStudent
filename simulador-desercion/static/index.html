Simulador de probabilidad de deserción

Cadena de 3 pasos: validar → calcular riesgo → intervenir. El riesgo se estima con una regresión logística sobre 4 dimensiones. Montecarlo se usa en dos lugares: para generar la cohorte sintética y para propagar la incertidumbre de los coeficientes.

1. Selecciona qué datos quieres evaluar

Elige una de las cuatro tarjetas para cargar o evaluar una cohorte. Cuando eliges el Dataset Real UCI, los datos vienen directamente del archivo real de estudiantes y los parámetros técnicos de generación se ocultan automáticamente.
